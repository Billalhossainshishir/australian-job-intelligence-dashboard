# Data directory

Project 5 deliberately avoids scraping prohibited job boards or redistributing live vacancy text.

The reproducible demo dataset is generated by `backend/app/demo_data.py` and mirrored by the GitHub Pages browser demo. It creates 240 deterministic Australian technology-job records from transparent role, location, company and skill dictionaries.

For a production version, replace the generator with a lawful API, open dataset, licensed feed or manually prepared source that permits reuse.
