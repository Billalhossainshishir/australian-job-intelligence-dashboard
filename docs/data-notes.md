# Data Notes

- The demo market contains **240 deterministic portfolio records** generated from transparent city, role, company and skill dictionaries.
- Locations cover multiple Australian states and cities, including Hobart and Launceston.
- Salary values are sample ranges only and are not market salary evidence.
- Records are **not live vacancies**.
- The generator makes the project reproducible without scraping or redistributing prohibited listings.
- Production ingestion should only use lawful APIs, open datasets, licensed feeds or sources that permit reuse.
